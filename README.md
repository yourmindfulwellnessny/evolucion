# Evolución · Mindful Wellness

Página del programa Evolución: 8 semanas de mentoría individual con Monica Villalba.

- `index.html`: página del programa (qué es, las 8 semanas, qué incluye, resultados, inversión y preguntas)
- `gracias.html`: página después del pago con tarjeta, que lleva a WhatsApp
- `config.js`: precio, cuotas, enlaces de pago de Stripe, Zelle, hoja de registro y WhatsApp
- `assets/`: logo, foto de Monica, portada del workbook, jardín y código QR de Zelle

Publicada con GitHub Pages en https://yourmindfulwellnessny.github.io/evolucion/
